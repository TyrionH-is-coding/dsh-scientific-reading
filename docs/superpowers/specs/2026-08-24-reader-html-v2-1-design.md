# 精读 HTML v2.1 收敛升级设计

## 决策摘要

精读 `reader.html` 需要修改，但不重做已经确认的 v2 美术风格。此次升级只解决两类问题：

1. 同时服务“连续精读”和“快速定位”；
2. 让重点、英文原文、图表和阅读位置具有稳定、可解释的交互语义。

页面继续是离线单文件阅读器，不发展为笔记应用、分析后台或图表画廊。主要新增一屏以内的
来源可追溯阅读导览、语义化黄/蓝重点、英文原文总开关和本地阅读位置恢复。

本设计补充并覆盖
`docs/superpowers/specs/2026-08-23-two-stage-literature-workflow-design.md` 中与精读 HTML 展示相关的
细节，不改变其数据所有权、PDF/MinerU/飞书或两段式工作流决策。

## 设计目标

- 用户可以像阅读论文一样连续向下阅读完整正文，不被摘要卡片、控制面板或双栏译文打断。
- 用户可以在一分钟内找到研究问题、关键方法、核心结果、局限和主要图表。
- 每个导览判断和重点都能跳回真实 source block，不产生脱离全文的第二份结论体系。
- 中文默认易读，英文原文随时可核对，但默认不把页面长度翻倍。
- 页面保持完全离线；状态保存只使用少量浏览器本地存储，不依赖服务端或飞书。
- 新设计不要求重解析已经生成的旧 HTML；旧文件继续按原样访问。

## 不在范围内

- 旧版结构化浅读或另一篇长摘要；
- 右侧常驻重点栏、第三栏或分析仪表盘；
- 段落笔记、书签、批注协作和飞书个人字段编辑；
- 独立图表画廊；
- AI 选择“关键图”；
- 第三种正文高亮色；
- 在线字体、脚本、样式、图片或遥测；
- 为升级样式而重新下载 PDF、重跑 MinerU 或移动旧资产。

## 页面骨架

桌面页面使用“可收起左目录 + 宽正文”，没有右侧常驻面板。

- 左目录展开宽度为 240–260px，包含章节、语义重点和图表标记。
- 正文宽度控制在 960–1080px；目录收起后正文居中扩展，但文本行不无限拉长。
- 题录位于正文顶部，阅读导览紧随其后，然后进入原论文的连续章节。
- 工具条 sticky 固定在正文顶部，滚动后仍能切换英文和重点模式。
- 浏览器宽度不足 1000px 时，左目录不再挤压正文，改成按需打开的临时抽屉。
- 打印时隐藏目录、工具条、阅读进度和交互提示，只保留文章、导览与图表。

页面不使用多个标签页拆分 Abstract、正文或图表。进入阅读器以后，全文仍是一条连续阅读流。

## 顶部阅读导览

### 内容

阅读导览最多占普通桌面的一屏，固定为四类：

1. 研究问题；
2. 关键方法；
3. 核心结果；
4. 局限性。

研究问题最多 1 条；关键方法最多 2 条；核心结果最多 3 条；局限性最多 2 条。每条中文文本
不超过 240 个字符，通常控制在 1–3 句话。导览不是自由摘要，不加入项目相关性、个人思考或
原文没有明确说明的内容。

### 来源

每条导览必须绑定 1–3 个 source block ID。点击【跳到正文】定位到第一个来源；存在多个来源时，
可以在同一条目内逐个跳转。来源必须属于当前解析代际，且不能只引用参考文献条目。

找不到可靠来源时，该条目不生成。四类都没有可靠内容属于精读审查失败，不能发布一个看似完整
但无法追溯的空壳导览。

### 与正文重点的关系

局限性只在阅读导览中总结并链接正文，不给对应正文增加第三种铺底色。其他三类可以引用黄/蓝
重点，也可以引用未高亮但提供必要语境的段落。

## 正文与英文原文

- 章节、段落、Figure、Table 和参考文献严格保持原论文顺序。
- 中文译文默认展开；英文原文用 `<details>` 按完整自然段收起。
- 工具条提供【展开全部英文】/【收起全部英文】，作用于正文和图表 caption 的原文。
- 同一列表或实验步骤中的连续短句合并成一个有序列表/阅读组，只出现一次英文展开入口。
- 不为每个短句重复显示“英文原文”。
- Figure/Table caption 中英对照；参考文献只保留英文，不生成空中文占位。
- 数学公式、变量、单位、代码、基因/蛋白名和引用编号保持源格式。

英文总开关只控制 disclosure 的开合，不删除 DOM 内容。打印时只打印已展开的英文，避免在用户
选择中文阅读时强制把打印页数翻倍。

## 语义重点

### 两种颜色

- 黄色 `result`：核心结果、主要结论和真正的创新性发现。
- 蓝色 `method`：理解结论所必需的关键方法、实验设计和支撑证据。

内部新合同和新 manifest 使用 `result`、`method`、`none`，不再把 `primary`、`secondary` 暴露为
用户语义。读取旧重点配置时可兼容映射 `primary → result`、`secondary → method`，但不重写旧
HTML，也不在新产物继续写旧枚举。

### 密度与粒度

- 总高亮硬上限为可高亮正文块的 25%；agent 提示目标为约 10%–15%。
- 优先标注能独立读懂的完整句；不随意只涂几个词，也不把整节铺色。
- 参考文献、纯标题、导航文字和装饰图不能进入重点。
- 同一块只能有一种语义；同时包含方法和结果时，以该段最主要的阅读用途为准。

### 三种显示模式

- 【隐藏重点】：移除正文底色、标签和目录彩色点，正文内容不变。
- 【只看重点】：保留顶部导览、章节标题、含重点的完整段落，以及紧邻这些段落的 Figure/Table；
  不把页面缩成失去语境的零碎句子。
- 【显示全部】：恢复完整连续正文和语义底色。

英文展开状态与重点显示模式互相独立。

## 目录与图表

### 目录标记

每个目录项根据其章节内容显示：

- 明亮黄色圆点：含 `result`；
- 明亮蓝色圆点：含 `method`；
- Figure 图标：含正文 Figure；
- Table 图标：含正文 Table。

圆点颜色保持高饱和度，但尺寸克制；悬停或键盘聚焦时显示“核心结果”“方法/证据”“图”或“表”
的文字说明。隐藏重点时只隐藏黄/蓝圆点，图表标记继续存在。

### 图表行为

Figure 和 Table 留在原文位置，不在顶部复制，也不生成阅读器内画廊。

- 点击 Figure 图片打开同一离线文件中的放大 dialog；Esc、关闭按钮和点击遮罩均可关闭，并把焦点
  返回原图。
- Table 保持原版式并允许水平滚动；提供【放大表格】打开 dialog，不能为了适配屏幕破坏列关系。
- 放大视图复用已经嵌入的内容，不加载新的本地/远程 URL。
- 做报告时使用独立 `exports/figures` 与 `exports/tables`，不从阅读器维护第二套导出逻辑。

## 固定工具条

工具条包含：

1. 目录展开/收起；
2. 展开/收起全部英文；
3. 隐藏重点；
4. 只看重点/显示全部；
5. 返回上次阅读位置。

按钮使用中文可见标签和 `aria-pressed`/`aria-expanded`，不只依赖图标或颜色。工具条在窄屏允许
换行，但不遮挡正文标题。

## 阅读位置恢复

阅读进度仅保存在浏览器 `localStorage`，不写 SQLite、HTML、飞书或日志。

每篇论文使用稳定 key，保存：`paper_id`、`reader_revision`、最近可见 block/section ID、滚动比例和
更新时间。`reader_revision` 是由 PDF、解析、翻译、导览和 reader 构建版本共同计算的输入身份，
不是会形成循环依赖的最终 HTML SHA。滚动写入采用节流，单篇只保存一条小记录。

恢复规则：

- URL 带正文 hash 时优先服从 hash，不自动跳回旧位置。
- reader revision 相同且没有 hash 时，打开后自动恢复最近 block；block 不存在时用滚动比例回退。
- reader revision 改变时，只在相同 block ID 仍存在时恢复到该块，不复用旧像素位置。
- 【返回上次阅读位置】可在用户随后滚动离开后再次回到本次打开时恢复的锚点。
- localStorage 不可用、损坏或被禁用时静默从顶部开始，不影响全文阅读。

不保存个人笔记、阅读内容或飞书字段。

## 离线、安全与兼容

- `reader.html` 仍是离线单文件，不引用 HTTP(S) 字体、脚本、CSS 或媒体。
- 所有导览文本、翻译、caption 和题录在渲染前进行 HTML escaping/sanitization。
- source block、paper ID、reader revision、reader SHA 和 PDF SHA 写入 `reader-manifest.json`，导览
  条目也记录来源。HTML 只嵌入 revision；最终 HTML SHA 只写 manifest。
- 旧 `reader_full.html`、旧 `reader.html` 和旧 highlight 枚举只读兼容，不批量重渲染。
- 新设计只对之后生成或用户明确重新生成的 reader 生效。
- 新阅读器的缓存身份必须包含 review/guide 合同与 reader 构建版本；样式或导览合同改变时不得错误
  命中旧 HTML 缓存。

## 错误处理

- 导览来源不存在、引用当前代际之外的 block、超过条目上限或文本为空：拒绝发布并请求 agent 修订。
- 高亮超过 25%、使用未知语义或引用参考文献：拒绝发布并请求修订。
- 放大 dialog 或 localStorage 脚本失败：保留基础正文和原位置图表，不能使页面白屏。
- HTML 与 manifest hash 不一致：不把 SQLite 标为精读完成。
- UI 状态切换不修改正文文件或 manifest，不产生新的工作流 job。

## 性能边界

- 导览和交互脚本直接写入现有离线 HTML，不新增网络请求和前端框架。
- 放大视图复用现有图片/表格，不重复嵌入一份 base64 资产。
- 目录、重点和图表标记在生成时确定，浏览器不重新分析全文语义。
- 滚动监听必须节流，并使用已有 block ID；不得在每次 scroll 全量扫描所有段落。
- 样式升级不增加 MinerU 或全文翻译次数；导览在已有 full-review agent gate 中一次提交。

## 验收标准

1. 1440×900 和 1280×720 下左目录与 960–1080px 正文均可读；收起目录后正文正确居中扩展。
2. 顶部四类导览在一屏附近完成，所有可见条目均能跳到当前 source block。
3. 中文默认展开，英文默认收起；总开关能一次切换所有正文与 caption 原文。
4. 新产物只显示“核心结果/结论”和“方法/证据”语义，不显示 primary/secondary 用户文案。
5. 高亮不超过 25%；参考文献和标题不能高亮。
6. 隐藏重点不删正文；只看重点保留完整段落、章节标题和紧邻图表。
7. 目录正确显示亮黄、亮蓝、Figure 与 Table 标记；隐藏重点不隐藏图表标记。
8. Figure/Table 放大 dialog 离线可用，Esc 后焦点返回触发元素。
9. 无 hash 时恢复阅读位置；有 hash 时尊重链接；reader 更新后不使用失效像素位置。
10. localStorage 禁用、dialog 脚本失败或窄屏时仍能完整阅读基础正文。
11. HTML/manifest/PDF SHA 可追溯，旧 reader 不移动、不删除、不自动重渲染。

## 测试策略

- Python 合同测试：full-review v2 导览结构、source block、语义枚举、密度、缓存身份和 manifest。
- renderer 测试：题录、导览、顺序、段落合并、双语 caption、参考文献、目录/图表标记与 escaping。
- DOM/JS 合同测试：英文总开关、三种重点模式、目录收起、dialog、hash 优先和 localStorage fallback。
- 离线安全测试：HTML 中无 HTTP(S) 资源，放大视图不发请求。
- 浏览器 QA：1440×900、1280×720、900×720；连续阅读、只看重点、图表放大和位置恢复。
- 兼容测试：旧 primary/secondary 配置可读取，旧 reader 路径继续服务，旧文件 hash 不变。

所有自动化使用虚构工科论文、本地 PDF/fake MinerU/fake agent，不读取飞书凭证，不触发网络或机构认证。
