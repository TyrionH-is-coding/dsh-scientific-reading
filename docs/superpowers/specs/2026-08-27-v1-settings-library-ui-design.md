# V1 设置页、解析后端与文献页收口设计

## 1. 背景与目标

当前插件已经具备入库、全文 parent job、文献导航、MinerU API、reader 和 Excel 快照等基线，但首个发布版仍有四个产品问题：

1. 首次使用时缺少统一的环境体检入口；
2. MinerU 只能使用 API，无法复用用户已经配置好的本机 MinerU；
3. API Key 只能通过环境变量提供，普通用户配置成本高；
4. 文献页同时展示大量状态和动作，挤压标题与核心入口，偏离“资料库导航”的主要责任。

V1 将这些问题收敛为一条完整体验：首次安装进入【设置与状态】完成环境准备；对话负责入库和复杂任务；【文献】页以紧凑列表管理资料库，并允许单篇或批量补齐 PDF；解析可使用经过验证的本机 MinerU 或 MinerU API；SQLite、PDF、HTML 和 Excel 共同构成长期个人文献库。

飞书退出 V1 产品路线。上游文献发现/推荐和下游逐篇 JSON 证据卡属于 V2，不进入本设计的实现与验收。

## 2. 导航与首次安装

插件提供两个原生页面入口：

- 【文献】：个人文献库导航、归类、单篇/批量补下载和产物入口；
- 【设置与状态】：环境体检、机构访问、解析后端、API Key、本地数据与版本信息。

数据根保存一个带 schema 版本的 onboarding 状态。首次成功安装或首次创建数据根时，DSH 默认打开【设置与状态】。进入该页面后记录当前 onboarding 版本已经展示；即使 MinerU、机构访问或 CloakBrowser 尚未配置，之后启动也不得反复强制跳转。用户始终可以先进行题录入库和 Abstract 管理。

页面首次展示只执行无副作用的本机静态检查，不联网、不启动浏览器、不运行 GPU 测试。机构会话、MinerU API 和本机 MinerU 的真实验证均由用户点击【重新检测】或【运行测试解析】触发。

## 3. 设置与状态页

### 3.1 总体状态

页面顶部显示四个聚合状态：

- PDF 下载：可用 / 部分可用 / 需要配置；
- 全文解析：本机可用 / API 可用 / 两者可用 / 未配置；
- 本地文献库：正常 / Excel 待刷新 / 回写冲突 / 数据目录异常；
- 可选增强：CloakBrowser 已安装 / 未安装且当前不需要。

状态使用上次检测快照并显示检测时间。打开页面不自动联网。任何错误必须给出下一步动作，不显示原始堆栈、命令行或密钥内容。

### 3.2 机构访问

显示：

- 当前机构名称和登录方式；
- 系统 Chrome 路径与版本；
- 插件专用 Profile 是否存在；
- 会话状态：未配置、尚未建立、存在但未验证、最近验证成功、已失效；
- 最近验证时间；
- 【登录/重新登录】与【重新检测】。

“最近验证成功”只表示机构入口会话在该时间可用，不承诺所有出版社均有权限。插件不保存账号、验证码或 MFA，也不读取用户日常 Chrome Profile。

### 3.3 下载环境

显示 OA/HTTP 基础链、系统 Chrome 和 CloakBrowser 三层状态。CloakBrowser 未安装时文案为“未安装（正常）”；只有明确检测到反自动化挑战后才推荐安装，安装后也只用于挑战子集，不成为默认下载后端。

### 3.4 MinerU 解析后端

本机 MinerU 卡片显示：候选命令或可执行文件、版本、模型完整性、CPU/CUDA 后端、GPU 可用性、最近检测时间和测试结果。插件只检测并调用用户已有环境，不自动安装 MinerU、CUDA 或模型，不修改用户 Python 环境。

MinerU API 卡片显示：Key 是否安全保存、是否已验证、最近验证时间、最近成功解析时间，以及【保存并检测】【替换 Key】【删除 Key】。页面不显示 Key 内容或末尾字符，并明确提示 API 解析会上传 PDF 至 MinerU 官方服务。

用户选择一个默认策略：

- **自动**：经过验证的本机 MinerU 优先，否则使用经过验证的 API；
- **仅本机**：本机不可用时停止并报告；
- **仅 API**：API 不可用时停止并报告。

V1 默认使用【自动】。provider 在创建解析任务时确定并写入任务状态和 generation manifest；任务开始后不得静默切换 provider。失败时保留 PDF 和断点，由用户明确选择是否用另一个后端重新解析。

### 3.5 本地文献库与诊断

显示：数据根目录、SQLite 健康状态、文献数量、可用磁盘空间、Excel 路径、最近生成时间、文件占用状态、待刷新/待回写数量和冲突数量。提供【打开数据目录】【打开 Excel】和【导出脱敏诊断报告】。

诊断报告只包含版本、状态码、时间和脱敏路径，不包含 API Key、Cookie、账号、论文正文、Abstract、用户笔记或完整本地路径。

## 4. MinerU provider 合同

本机和 API 必须进入同一条规范化与发布链：

```text
Local MinerU ─┐
              ├─ provider 原始结果包
MinerU API ───┘
                     ↓
             MinerUNormalizer
                     ↓
       source_map / Markdown / 图片 / 表格
                     ↓
          统一资产校验、manifest 与发布
```

provider 至少实现：

- `probe()`：返回可执行性、版本、模型/凭据状态和能力，不产生解析资产；
- `parse(pdf, staging_dir)`：只写入隔离 staging，返回 provider ID、版本、原始结果身份和解析元数据；
- `cancel()`：终止当前 provider 子进程或 API 轮询；
- 统一错误分类：未配置、不兼容、模型缺失、凭据无效、额度不足、超时、解析失败和结果无效。

本机 MinerU 仅支持经过验收的版本范围。它由隐藏子进程运行，默认串行，支持取消和超时。无论来源为何，原始结果都必须通过路径边界、PDF SHA、正文块、图片/表格引用和 generation identity 校验；不接受任意目录作为已完成结果。

manifest 记录 `provider_id`、provider 版本、解析方法、规范化版本、源 PDF SHA 和原始结果 SHA，使同一文章的不同解析来源可以追溯且不会误命中缓存。

## 5. MinerU API Key 安全合同

Key 不进入普通 DSH `Config`、composition、SQLite、Excel、job JSON、命令参数、日志、错误堆栈或诊断报告。

Windows V1 使用当前用户作用域的 DPAPI 加密 Key，将密文保存在数据根的独立 secret 文件并限制 ACL。设置页通过同源 POST 写入；接口校验 Origin 和 CSRF token，拒绝跨源请求。响应只返回“未配置、已保存未验证、验证成功、无效/过期”及密钥来源，不返回密钥内容。

保存后前端立即清空输入框和内存引用。引擎调用 API 前才临时解密，并只向当前解析 worker 注入 `MINERU_API_TOKEN`；宿主全局 `process.env` 不被修改。

密钥来源优先级为：

1. 用户在设置页明确保存的 DPAPI 密钥；
2. 启动 DSH 时已有的 `MINERU_API_TOKEN` 环境变量；
3. 未配置。

页面显示来源但不显示内容。DPAPI 文件复制到另一台机器或另一个 Windows 用户后不可解密，页面应要求重新输入。该机制防止普通配置、备份和日志泄露，但不承诺抵抗已经取得同一 Windows 用户权限的恶意程序。

## 6. 文献页信息架构

### 6.1 页面责任

文献页主要回答四个问题：有哪些论文、如何归类、PDF/HTML 是否可打开、如何在 Excel 中定位。入库、开始精读、复杂重试、provider 选择和诊断继续由对话或设置页承担。

### 6.2 两行式紧凑列表

使用高密度两行列表，不使用六列宽表格或卡片网格。每篇文献结构为：

```text
□  文献标题                                      [打开 PDF] [打开 HTML] [定位 Excel]
   作者 · 年份 · 期刊       标签 1  标签 2  +N       文件夹/瞬时状态
```

第一行保留选择框、最多两行标题和右侧固定动作。第二行保留作者、年份、期刊、最多三个标签；多余标签显示 `+N`。文件夹只在【全部文献】、搜索结果和标签筛选中显示，进入具体文件夹后隐藏。

标题点击打开详情抽屉；不再设置独立【浅读】按钮。抽屉按需展示完整作者、主要研究单位、DOI/PMID/arXiv ID、来源链接、双语 Abstract、详细错误和资产目录。

### 6.3 动作状态

- 无 PDF：显示【获取 PDF】，不显示 HTML 动作；
- PDF 下载中：显示不可重复提交的【获取中】；
- 已有 PDF：显示【打开 PDF】；
- HTML 生成中：显示不可重复提交的【生成中】；
- 已有 reader：显示【打开 HTML】；
- PDF 失败：显示【重试 PDF】并把详细原因放入抽屉；
- 【定位 Excel】始终显示。

【定位 Excel】只接收 `paper_id`。本地后端根据稳定身份查找工作簿和表格行，再请求 Excel 打开并选中该行；客户端不得提交任意路径、工作表名、单元格或命令字符串。

列表移除浅读/精读/飞书状态列、独立浅读按钮、开始精读、更多菜单、图表整理、DOI/PMID、详细错误、Abstract 正文和维护时间。异常或运行中的论文只显示一个简短瞬时状态，不增加常驻状态列。

### 6.4 筛选与批量操作

普通工具栏只保留搜索、年份、期刊、标签和阅读状态。选中文献后，同一区域切换为：

```text
已选 N 篇 | 下载缺失 PDF | 移动文件夹 | 添加标签 | 移除标签 | 取消选择
```

两套工具栏不同时展示。批量下载自动排除已有 PDF，按钮显示实际缺失数量；单篇失败不终止整批。窗口变窄时动作移动到第二行末尾，不压缩标题，也不依赖页面横向滚动。

## 7. PDF 批量降级

对话和文献页共用同一批量下载服务：整批先尝试 OA/HTTP，再聚合剩余项目并只启动一次系统 Chrome 专用 Profile。明确反自动化挑战集中到一个子集；已安装 CloakBrowser 时才重试该子集。最终未成功项目进入手动挂接状态。

页面只展示一个批次汇总和每篇简短状态，不逐篇弹窗。整批结束后集中报告 OA/HTTP 成功、Chrome 成功、反自动化待处理、等待手动 PDF 和最终失败。重试只处理未成功项目。

## 8. Excel 所有权与定位

SQLite 继续保存系统事实。Excel 是美观的长期维护表格，只允许个人思考、个人理解程度和用户笔记白名单回写；系统字段、文件夹和标签不得从 Excel 覆盖 SQLite。

每行持有不可编辑的稳定 `paper_id`。回写和定位都按该字段匹配；身份缺失、重复或变化时停止对应行并报告，不使用题名猜测。Excel 被占用时刷新/回写进入 pending，不回滚入库、下载或精读。

## 9. 错误与恢复

- 设置页探测失败只更新探测快照，不改变已有论文或任务；
- Key 验证失败保留加密值并标记无效，用户可替换或删除；
- 本机 MinerU 版本变化后状态回到待检测，已有 generation 不受影响；
- provider 失败保留 PDF、staging 诊断摘要和 parent job，不发布不完整 generation；
- Excel 定位失败只报告工作簿未生成、Excel 不可启动或行身份异常，不执行任意文件回退；
- DSH 重启后恢复批量下载、精读 parent job 和 Excel pending 状态。

## 10. 验收门禁

### 设置页

- 全新临时数据根首次打开设置页，第二次启动不再强制跳转；
- 首次展示无网络、浏览器、GPU 或真实 API 调用；
- 手动重新检测能区分缓存、成功、失效和未配置；
- 未安装 CloakBrowser 显示正常而非错误；
- 诊断报告不包含密钥、Cookie、论文内容或用户字段。

### 密钥

- 普通 DSH Config 和序列化输出不存在 MinerU Key 字段；
- DPAPI 密文不包含明文，换用户/机器不可直接解密；
- CSRF、跨源、日志、argv、job JSON 和 HTTP 读回均无法取得 Key；
- 环境变量回退和安全存储优先级符合合同。

### MinerU

- 使用假本机 provider 和假 API provider 证明自动、本机、API 三种策略；
- 任务开始后 provider 不静默切换；
- 两种 provider 经过同一规范化、资产校验、manifest 和 cache identity；
- 本机版本不兼容、模型缺失、取消、超时和输出越界均安全失败。

### 文献页与批量下载

- 60 篇虚构工科题录在常用桌面宽度无横向页面滚动；
- 列表只显示已批准信息和动作，标题抽屉保留双语 Abstract 与详细元数据；
- 单篇/批量下载排除已有 PDF，单篇失败不阻塞其他项目；
- 一批任务最多启动一次普通 Chrome 会话，并集中提示挑战子集；
- Excel 定位只接受 `paper_id`，无法注入路径、单元格或命令。

### 资产与回归

- PDF、reader、Figure/Table、manifest 和旧 generation 不移动、不删除、不无故重算；
- Excel 白名单回写、占用 pending 和身份冲突通过真实工作簿验收；
- 真实 tarball、临时 Profile、HTTP、浏览器关闭清理和重启恢复门禁通过；
- 自动测试只使用虚构工科题录、假 API、本地测试 PDF 和临时数据根，不触发真实机构认证、真实 MinerU 消费或外部写入。
