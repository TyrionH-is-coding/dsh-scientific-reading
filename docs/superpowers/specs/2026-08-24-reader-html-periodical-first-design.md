# 精读 HTML：期刊正文优先设计

## 决策摘要

精读 `reader.html` 改用“期刊正文 + 轻量增强”布局。打开页面后，用户应先看到论文，而不是一套
AI 分析报告：题目和紧凑题录之后立即进入摘要；阅读导览、重点语义、英文原文和来源追溯退到
按需出现的辅助层。

本设计覆盖 `2026-08-24-reader-html-v2-1-design.md` 中的页面骨架、顶部阅读导览、固定工具条和
视觉呈现细节。其余数据合同、来源锚点、重点枚举、图表顺序、阅读位置、离线安全、旧产物兼容
和两段式工作流保持不变。

## 目标与成功信号

- 1440×900 和 1280×720 下，首屏均能看到摘要正文的开头。
- 页面第一印象是论文正文，而不是仪表盘、知识卡片或 AI 报告。
- 连续阅读时，正文是唯一视觉主角；目录、导读、英文和来源只在需要时出现。
- 用户仍能快速找到研究问题、方法、结果、局限、Figure 和 Table，并跳回对应 source block。
- 页面继续是离线单文件，不增加前端框架、网络资源或新的 agent 步骤。

## 保留边界

- 中文译文默认显示，英文原文完整保留并可全局展开。
- 黄色表示核心结果/结论，蓝色表示关键方法/证据；不新增第三种重点色。
- 只看重点时保留完整段落、章节标题和相邻图表，不抽成无语境短句。
- Figure、Table 和参考文献保持原论文顺序；图表仍可离线放大。
- 每条导读和重点继续绑定当前解析代际的 source block。
- 旧 `reader.html`、`reader_full.html`、PDF、MinerU 和导出资产不移动、不批量重渲染。

## 不在范围内

- 笔记、批注、聊天、RAG、跨论文分析或飞书字段编辑；
- 右侧常驻 AI 面板或第三栏工作台；
- 独立图表画廊或 AI 选择“关键图”；
- 原文与译文左右并排；
- 为视觉升级重新下载、解析或翻译论文。

## 页面结构

### 1. 阅读画布

桌面端保留“可收起左侧栏 + 中央正文”，但视觉上只存在一张连续纸面：

- 页面背景使用低对比暖灰，正文区域使用暖白；正文不再包在带圆角、阴影和完整边框的大卡片中。
- 文字列宽为 760–820px；Figure 和 Table 可向两侧扩展到 980–1040px。
- 正文不因侧栏收起而无限变宽；侧栏收起后只重新居中。
- 不显示 `FULL READING`、段落数量、重点数量或“离线单文件”等产品状态标签。

### 2. 首屏顺序

主阅读流严格使用以下顺序：

1. 论文中文题目；
2. 英文题目；
3. 作者、期刊、年份和 DOI 组成的一至两行紧凑题录；
4. 一条轻分隔线；
5. 摘要标题和摘要正文；
6. 后续原论文章节。

题录区不使用统计 chip、功能说明卡或大面积留白。四类阅读导览不再占据正文首屏。

### 3. 左侧栏

左侧栏是唯一的快速定位层，宽度为 250–270px，按顺序包含：

- “导读”：研究问题、关键方法、核心结果、局限性各一条紧凑入口；关键方法和核心结果有多个来源
  时在同一入口下显示多个小锚点，不复制长段落。
- “目录”：原论文章节、Figure、Table，以及黄色/蓝色重点小标记。

导读默认只显示每项的一行摘要。项目标题旁的来源链接跳到首个 source block；独立的展开按钮显示
完整导读和其他来源，避免同一点击同时承担“展开”和“跳转”。侧栏可收起。窄于 1000px 时改为
覆盖式抽屉，不挤压正文。

## 工具条

工具条保持 sticky，但只显示三个控制组：

1. 【目录】：打开或收起左侧栏；
2. 【语言】：`中文` / `中英`；
3. 【阅读】：`全文` / `无标记` / `重点`。

`全文` 显示完整正文和重点底色；`无标记` 显示完整正文但隐藏重点；`重点` 对应原“只看重点”。
“返回上次阅读位置”不再常驻为按钮：页面仍自动恢复位置；确有已恢复位置时，只在侧栏底部显示
一个克制的“回到上次位置”文本入口。

工具条不显示全文状态、计数 chip 或解释性文案。分段控件必须支持键盘、可见焦点和正确的
`aria-pressed` / `aria-expanded`。

## 正文排版

- 中文正文使用本地系统中文衬线字体栈，字号 17.5–18px，行高 1.8–1.9。
- 英文使用 Georgia 或系统衬线字体，字号略小于中文，颜色降低一级。
- 二级标题与正文之间依靠字号、字重和垂直留白建立层级，不使用章节卡片。
- 段落默认无边框、无圆角、无背景块；列表保留自然缩进和连续阅读节奏。
- Caption 和来源信息使用无衬线小字，与正文形成明确但克制的辅助层级。

## 英文与来源追溯

- 中文模式下，每个自然段或连续列表组只显示一个小型 `EN`/“原文”入口，位于段末或页边，不另占
  一整行按钮区。
- 中英模式下，英文直接在中文下方展开，以细左线和较浅文字区分，不使用新的卡片容器。
- 连续短句或实验步骤继续合并为一个阅读组和一个英文入口。
- source block、页码和块号只在英文展开区或点击来源入口后显示；不在中文正文中反复常驻。

## 重点呈现

- 重点使用低饱和透明底色贴合句子或自然段文本，不再给整块添加明显边框、圆角或彩色侧栏。
- 黄色与蓝色标签默认缩成页边小点/短线；悬停、键盘聚焦或点击后才显示“核心结果/结论”或
  “方法/证据”及理由。
- 窄屏没有稳定页边空间时，小点移到段落末尾；不得覆盖正文或形成单独的标签行。
- 目录中的黄蓝标记保持明亮，正文中的底色保持柔和；二者分别承担“定位”和“阅读”职责。
- 隐藏标记只改变视觉，不删除正文；重点模式仍保留确定性语境。

## 图表与参考文献

- Figure 和 Table 留在正文位置，可比文字列更宽，但不能造成整页横向滚动。
- Figure 图片直接可点击放大；Table 在原位允许局部横向滚动并提供放大入口。
- Caption 紧贴图表，先中文后可展开英文；不使用独立图表卡片墙。
- 参考文献只保留英文，并使用更紧凑的字号和行距。

## 响应式与打印

- 1000px 以下侧栏变抽屉；720px 以下工具条允许紧凑换行，但三个控制组的顺序不变。
- 手机宽度下题目减小、题录自然换行，摘要仍紧随题录，不插入导读卡片。
- 打印时隐藏侧栏、工具条、阅读进度、交互入口和 dialog trigger，只打印当前语言模式下的论文。

## 实现边界

- 先修改独立 `reader-v21-demo/reader.html` 并完成浏览器视觉验收，再把同一设计迁入
  `Scientific-Reading-for-Newbies/reader/build_reader.py`。
- 演示页和生产构建器共用同一组视觉 token 与 DOM 语义，不维护两套不同交互。
- 不改变 full-review、guide、highlight 或 manifest 的 JSON 合同；只改变既有数据的布局和交互映射。
- 新样式必须提高 reader 构建版本，避免命中旧 HTML 缓存。

## 验收标准

1. 1440×900 与 1280×720 首屏可见摘要正文，900×720 首屏至少可见“摘要”标题。
2. 正文主流中不存在四张导读卡、统计 chip、`FULL READING` 或大卡片外框。
3. 工具条只有目录、语言和阅读三个控制组；三种阅读状态与两种语言状态均可逆。
4. 左侧栏同时提供紧凑导读、章节、黄蓝重点和 Figure/Table 定位。
5. 中文模式不因重复“英文原文”按钮破坏节奏；中英模式能一次展开全部原文。
6. 重点底色柔和且无块级卡片感；隐藏标记与重点模式保留原有语义。
7. Figure/Table 可读、可放大且不产生远程请求；参考文献保持英文。
8. 阅读位置恢复、URL hash、键盘焦点、打印和窄屏降级继续通过。
9. HTML 保持离线单文件；旧 reader bytes、路径和资产不变。

## 测试与视觉审核

- renderer/DOM 测试锁定首屏结构顺序、三个控制组、导读侧栏和无重复英文入口。
- 交互测试覆盖语言与阅读状态组合、目录抽屉、图表 dialog、hash 和位置恢复。
- 离线测试继续断言无 HTTP(S) 资源和无运行时网络请求。
- 浏览器分别检查 1440×900、1280×720、900×720 和 390×844；重点观察首屏、长段落、列表、
  Figure、Table、参考文献以及滚动后的工具条。
- 视觉验收使用虚构工科论文，不联网、不读取飞书凭证、不触发下载或解析。
