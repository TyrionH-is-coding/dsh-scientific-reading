# v0.2 候选版使用指南

当前源码版本为 `0.2.0-rc.2`，Python 引擎为 `0.2.0rc2`，数据格式为 6。v0.2 尚未发布正式安装包；源码构建和候选包请核对来源提交、包 SHA 与清单。

## 各步骤的模型与思考深度

右侧“文献设置”中的模型分工覆盖：雷达方向、候选评估、摘要翻译、全文与图注翻译、全文导读与重点高亮、分类建议、研究字段、单篇讨论、Figure 讨论、多篇综合、阅读悬浮对话。连接 Codex 订阅且模型可用时，翻译默认 GPT-5.6 Luna，其余默认 GPT-5.6 Sol，思考深度默认 **medium**。未连接的模型不加入选项；只连接其他服务时，请从实际模型列表中选择。

先连接模型服务，再分别选择模型、思考深度并点击该行“保存”。设置保存在本库的 SQLite 中，下一次模型请求生效；已开始的请求使用原来的配置。下拉列表来自当前连接的模型能力；若模型未提供 medium，可选择其支持的档位或“模型默认”，不会悄悄替换成其他模型。DSH 0.1.5-rc.1 新增的 DeepSeek-V41-Flash（deepseek-flash）支持文字和图片，思考档位为 off、low、high、max；选用它时请按实际档位设置，或使用“模型默认”。

原生文献 chat 按真实任务 gate 切换翻译和导读模型，其他分析步骤由 `sr_model_step` 选择。Codex 总管理员自己的模型由 Codex 控制，生成工作台内容时通过 `model_run` 调用这里的配置。后者只生成文字，仍需按原合同核验并提交。

## 在线阅读助手与离线分享

打开在线 Reader，右下角“问 AI”入口可展开本页对话，直接提问或先选中正文、图注、译文。**Alt+Shift+E** 解释当前选区；输入框支持 Ctrl+Enter 发送，也可点击发送。手机可先选中文字，再点“问 AI”。支持追问、停止生成、清除选区、新对话和回到引用段落。

选中译文时，后台同时带上对应原文及相邻段落；每次核对 PDF 身份和选区内容。无选区时提供摘要与相关段落，不能把这当作读过完整论文。悬浮助手当前处理文字；图像仍从 Figure 讨论入口提交给支持图片的模型。

点击“导出离线 HTML”可保存单个文件，包含原文、译文、导读、目录、公式和内嵌图片。文件适配手机宽度，可在支持 HTML 的浏览器中离线阅读；不包含本页对话、模型配置或登录信息。导出文件禁止联网，保留原有阅读交互。本页对话用于即时讨论，刷新页面或工作台重启后不保证保留。

“在线”表示连接正在运行的文献工作台，尚未部署公网服务。手机验收使用 390 像素浏览器模拟，未在 iOS/Android 实机逐一验证；部分聊天应用的文件预览器会禁用 JavaScript，完整阅读请用浏览器打开。

## 单篇 chat 与所选历史

在文献详情打开本篇 chat；重复打开、重启、移动分类后都复用同一个会话。每轮工具只操作绑定论文，跨论文总结由管理员在文献页明确选择多篇 chat 并填写问题后执行。读取结果带 paperId、sessionId、历史页范围、来源指纹和截断提示。需要续页时保留上一页 SHA，不把未读取部分写成已读。

旧分类讨论和旧 Review 从“旧会话历史”只读查看。混合讨论保留其原身份，不自动转为论文结论。聊天推测、用户笔记和已确认的论文结果分别保留来源。

## Figure 连续讨论

在已生成 Reader 的图下输入问题并选择“讨论此图”。系统核对 PDF 指纹与 assetId，把真实 PNG、图注、明确引用该图的正文及相邻段落送入本篇 chat；换图继续同一会话。收到提交回执后才能称图像已送达。正文没有明确引用时会标明缺口。

模型不支持图片时可选择仅文字模式；回答须说明未看到图像。图上能看见的内容、作者解释和后续推测应分开表述。纯外观切换保留 PDF、解析、正文和译文；已有 Reader 的显示响应可补入讨论入口。

## Excel 显示方案与研究字段

在“Excel 列与研究字段”设置列隐藏、顺序、显示名、宽度与自动换行，保存全局或分类方案并应用。分类默认优先于全局默认，分类可复用全局方案。文献身份与字段 ID 不随显示名变化。

自定义研究字段可人工填写，也可让本篇 AI 根据当前摘要或已验证正文填写。AI 值必须附来源短引文、摘要 SHA 或正文定位；采用版本检查，不能覆盖人工值。工作簿的“研究字段”页保留来源和修订信息。

SQLite 是事实源，Excel 是派生视图。个人记录按导出基线安全回写；版本冲突、未知表头或损坏合同会暂停写回。整表排序，保存关闭后刷新。不要删除隐藏的“_同步”页；换机请复制完整库而非只有工作簿。

## 主题色与 Reader 模板

设置页提供暖纸、纯白、深墨、雾蓝四套外观预览，点击后保存。配色同时应用于文献库和 Reader，不再提供取色器或色值输入。Reader 外观中的“主题设置”进入同一套主题选择；其余选项包括字体、字号、正文宽度，以及原文、交错双语、左右双语、中文优先布局。

HTML 模板是包住原 Reader 的片段，必须恰好包含一次 `{{content}}`。例如：

```html
<section class="lab-reader"><header><p>课题阅读</p></header>{{content}}</section>
```

可导入 `.html` 和 `.css`。允许容器、标题与文字标签；不允许脚本、事件属性、外部 CSS 资源或删除正文占位符。CSS 示例：

```css
.lab-reader > header { padding: 16px; border-bottom: 2px solid var(--accent); }
```

先“预览并校验”，成功后保存并应用为当前范围默认；继续修改会重新禁用应用，直到校验通过。“恢复继承或内置外观”清除该范围默认。应用只生成显示响应，正文、译文、图、表、公式和定位 ID 保持原样。校验失败保留当前 Reader。

## 文献雷达

1. 写清研究问题、研究目标、概念组、纳入排除条件、已有种子文献、时间范围与频率。
2. 保存草稿并查看将发送给 Europe PMC、Crossref 的查询；用户确认后才开始发现。修改配置会撤销确认。
3. 结果先进入候选区，多源按 DOI/PMID 去重；缺身份时只在题名、年份、首作者匹配且无已知身份冲突时合并。每条保留来源记录与查询信息。
4. 管理员根据可读取的摘要或全文分别评估方向相关性、研究设计、阅读价值和时效性，并附可核对短引文。元数据初筛不能证明全文质量；预印本、撤稿/更正线索和未核对项需保留。
5. 用户可标记相关、不相关、稍后再看并填写原因。明确点击“纳入文献库”后才入库；发现或 AI 评估不触发入库和 PDF 下载。

初次发现限制每个查询的返回数量，界面报告覆盖范围。增量扫描保存窗口与游标，部分失败不推进失败来源；重跑继续发现并去重，不承诺完备检索。配置了频率且工作台运行时才定期扫描；未完成分页按分钟续接。定期扫描负责发现，相关性仍需管理员评估。只提示尚未通知过、评估仍有效的新相关候选；无变化时保持安静。可暂停并手动扫描。

## 安装、升级与验收范围

本轮框架固定适配 DSH `0.1.5-rc.1`，已迁移 Gateway、设置注册、会话 V3 和前端模块接口。按现有本地插件安装流程安装候选 tgz，再运行 `sr_setup` 安装其内置引擎。开发构建用 `npm ci --ignore-scripts --legacy-peer-deps` 和 `npm run build`，不要使用旧 `engine/build` 目录中的残留文件构建 wheel。

升级前关闭旧进程并备份整个库。迁移格式 4/5 至 6 时自动创建 SQLite 备份；它不能替代包含 PDF、会话与资产的完整备份。格式 6 库不直接降级写入，恢复旧版须用独立目录和升级前备份。

A 只提供 OA 获取或用户导入 PDF；机构浏览器协作由 Deep Literature for Codex 承担。授权登录不等于取得 PDF，HTML 登录页不算全文。

工程验收使用独立 Profile、端口和合成模型，检查真实宿主的会话、工具、附件字节、Reader、Excel 与雷达公开接口。它不代表真实模型的科学回答质量、真实机构账号权益或所有操作系统实机验收。最终证据见随交付提供的验收报告与包清单。

## 本轮框架补齐（2026-09-09）

左侧把手可收起或展开导览和目录；阅读导览可单独折叠。窄屏使用抽屉，点击遮罩或按 Escape 收起。文献库与设置从工作台右上角打开，在宿主右侧栏中切换、收起或展开；空白会话也可直接进入，无需先调用模型。

“随记”与“问 AI”并排，共用侧面板，写入本文已有的用户笔记。支持摘录选区、保存、Ctrl/Cmd+Enter 保存和“打开 Excel”。AI 回答可存入草稿，并标注“AI 解读（待核对）”；仍需点击保存。刷新后随记保留，本页 AI 对话不保留。离线 HTML 不包含个人随记。

打开 Excel 前会保存随记、同步文献总表，再定位本文。若其他页面修改了笔记，保留当前草稿并要求重新载入；若 Excel 被占用或有不同修改，保留已存随记并提示处理，不覆盖原表。

### Codex 接入与 Astra

独立版通过私有 Codex app-server 连接 ChatGPT 账号；模型列表及思考深度来自账号实时返回的能力，按分页读取全部模型。返回列表包含 GPT-6 Astra 时可选用，不限制为 Luna/Sol。当前已验证 Astra 的模型发现和文本路由合同，尚未用真实账号完成 Astra 调用。

Deep Literature for Codex 的适配器已补齐图片传输，可从原生对话或“讨论此图”提交图片；图片能力以账号返回为准。已通过真实 Codex 进程与本地模拟模型端点的图片字节校验，真实账号的 Astra 识图效果尚未实测。Reader 悬浮“问 AI”仍用于文字选区。

### DSH 0.1.5 升级

旧文献预设仅将 persona 的 text 字段迁到 prefix，先保留原文件备份，不替换用户自定义正文。DSH 会迁移旧会话为 V3；独立版升级后禁止回退到会读取旧会话格式的宿主。升级前保留完整库与会话备份。

启动入口使用本次 start/status 返回的 entryUrl，让 DSH 完成浏览器认证；不要沿用旧端口或手工拼接未认证的根地址。启动令牌只保存在管理进程内存中，不写入持久运行状态。

本轮为 v0.2 候选版源码。真实账号的模型可用性及识图效果、跨平台完整安装和真实旧库升级仍需各自验收；合成模型测试不代表真实模型回答质量。
