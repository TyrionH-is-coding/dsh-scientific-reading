> 状态：✅ 已实现并实测　🟡 已实现待演练　⏳ 规划中

---

## 0. 一句话介绍

在 DSH 里加一个**文献工作箱**：你说一句"帮我读这篇论文（DOI/题名）"，
它自动完成 **下载 PDF → 解析 → 生成中文笔记 → 存进本地文献库**，
全程在对话里可见、可恢复；还有一个**【文献】标签页**，像 Zotero 一样管理全部论文。

**不需要 Zotero Desktop**——文献库整个搬进了 DSH。

## 2. 功能清单

### 2.1 文献下载（Phase 0，✅ 已实测）

## 3. 日常用法（最终版）

| 你想做什么 | 怎么操作 |
|---|---|
| 读一篇论文 | 对话里发 DOI/题名："帮我读这篇 10.48550/arXiv.1706.03762" |
| 管理论文 | 打开【文献】标签页：搜索、点开详情、看笔记 |
| 手动入库 | 文献页点"添加"，或对话里说"收录这篇论文（附元数据）" |
| 下付费论文 | 设置里填学校 → 对话/文献页点"机构登录" → 浏览器里登录 → 再下载 |
| 看精读 | 说"精读这篇"，生成后文献页打开双语 HTML |
| 同步飞书 | 说"同步到飞书"，先看预览再确认 |
| 换电脑 | 拷走数据文件夹 + 插件，重装即可 |

## 4. 安全与边界（一直不变）

1. **合法下载**：默认只走合法来源（arXiv/开放获取/学校机构访问）；Sci-Hub 等灰色来源默认关闭，开启是你的选择；
2. **密码不经过插件**：学校账号、验证码、MFA 只在你自己的浏览器页面里输入；
3. **数据边界**：论文、笔记、任务状态全在仓库外的数据文件夹，删插件不删数据；
4. **写操作要确认**：入库新条目、写飞书都需要你点头；
5. **不编造内容**：笔记每条结论都绑定原文段落，找不到依据就明说。

## 6. 常见问题

**Q：还要装 Zotero 吗？** 不用。文献库是插件自带的 SQLite。

**Q：学校登录麻烦吗？** 第一次配一次（弹浏览器登录），之后自动复用会话，失效了会提示重新登录。

**Q：能下所有论文吗？** 开放获取/学校有权限的基本都能；都没权限的会提示你手动下载，然后拖进文献页即可。

**Q：笔记是中文的吗？** 是。默认生成约 1000–2000 字的中文九节笔记，带关键图和原文定位。
