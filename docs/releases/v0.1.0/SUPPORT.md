# 问题处理与数据流向

## 常见问题

| 现象 | 先做什么 |
| --- | --- |
| 没有“文献”入口或模型不会使用文献工具 | 安装/更新后重启对应 DSH，在新会话选择“文献模式”；核对安装和启动使用同一环境 |
| 找不到 `dsh`、`pnpm`、Node 或 Python | 重新打开终端并检查版本；保留原始安装错误，不重复启动多个安装进程 |
| 3080 打不开或显示另一套 DSH | 核对该实例实际使用的端口和启动窗口；不要根据端口号直接结束不明进程 |
| 已有题录，但摘要为空 | 查询后台状态；来源可能没有摘要，保留待补状态，不把生成的介绍作为原始摘要 |
| PDF 下载没有完成 | 查看是否有 OA 文件；需要机构访问时先自行取得文件，再补入对应文献 |
| 文件能打开网页，却不能挂接为 PDF | 可能保存的是登录页或错误页；重新获取正文文件并核对题名 |
| MinerU 显示已配置，解析仍失败 | 保存 Key 与服务可用是两件事；查看具体错误码，再检查有效期、额度或网络 |
| 精读停在等待用户/Agent 的阶段 | 继续原会话，按任务提示补文件或继续翻译/审核；不要新建重复任务 |
| Excel 刷新 pending 或无法替换文件 | 先保存并关闭 Excel，再继续刷新；已入库记录不会因此撤销 |
| Excel 身份冲突或表结构异常 | 保留当前工作簿和笔记，恢复规定的列名/标识后重试；不要直接用空表覆盖 |
| 旧 Reader 未就绪、版本不匹配或定位失效 | 保留旧 PDF 和阅读资产，记录错误码；修复来源对应关系后重新生成，避免手工修改 manifest |
| 恢复目标目录被拒绝 | 使用不存在或空的新目录；恢复不会覆盖已有库，也不会自动切换当前库 |

## 哪些内容留在本地，哪些处理会联网

| 操作 | 数据流向 |
| --- | --- |
| 文献库、笔记、PDF、Reader、Excel、导出文件 | 默认保存在用户的数据目录 |
| 元信息查询与 OA 获取 | DOI、题名或检索词发送给对应文献来源；文件从提供方下载 |
| DSH 对话、摘要/全文翻译、解读 | 相关输入与工具返回由 DSH 交给用户选定的模型；范围受会话和模型配置影响 |
| MinerU API 解析 | 待解析 PDF 上传到 MinerU 服务，解析结果下载到本地；因此选择适合发送给该服务的材料 |
| 可选本机 MinerU | 解析在已配置的本机环境中执行；首次安装或模型准备仍可能联网 |
| 整库备份 | 输出到用户指定的库外位置；产品备份排除运行环境和凭据 |

MinerU API Key 在 Windows 当前用户作用域下加密保存。换电脑或 Windows 用户后应重新配置；不要把密钥复制到聊天、Excel、Git 或问题附件。DSH 宿主及模型服务自身的数据策略以各自设置和说明为准，本插件不替它们承诺全程离线或无遥测。

## 提交问题

使用[GitHub 问题表单](https://github.com/TyrionH-is-coding/dsh-scientific-reading/issues/new?template=bug_report.yml)，尽量提供：

1. 插件版本、DSH 版本、Windows/Node/Python 版本，以及从 `.tgz` 安装还是源码安装。
2. 最短复现步骤、预期结果和实际结果；第一次出现还是升级后出现。
3. 任务错误码、当时的任务阶段、相关日志的少量片段；截图可以只截取出错区域。
4. 方便公开时提供 DOI 或公开样例；不方便公开时，使用能复现问题的原创小样例。

不用上传整个文献库、数据库备份或浏览器 Profile。日志和截图提交前去除密钥、Cookie、验证码、账号、私人路径和未公开研究内容。如果页面没有显示版本，可直接说明“不清楚”，不影响提交。

维护者收集到复现信息后，应区分元数据来源、下载、解析、翻译、Reader、Excel 和宿主安装问题，避免让用户反复重装全部环境。
