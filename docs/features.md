最新[内容保真与发布验收](superpowers/executions/2026-09-05-content-fidelity-release.md)补充了 PubMed 修复、最终安装包和重启实测；真实历史论文的 R1 内容验收仍未通过，不能据离线测试宣称整个 V1 已验收。

## 首个发布版验收范围

### 入库与导航

- **已有基线**：DOI、PMID、arXiv ID、题名与作者录入；稳定标识优先查重。
- **已有基线**：本地事务先返回，题录补全和 Abstract 中英对照在后台继续。
- **本轮修复**：PubMed 标题和主摘要保留内联标签中的文字及其后续内容，多段摘要保留标签/分段；无摘要保持缺失，不混入 OtherAbstract。已有摘要的派生状态为空时可正常通过 HTTP 读回。纯文本字段不保留上下标排版或完整 MathML 语义。
- **已有基线**：全部文献、待归类、文件夹、标签、搜索、筛选、分页、跨页选择和批量归类。
- **已整合代码**：文献页回归资料库导航；精读排队、复杂重试等通用任务控制移回对话。
- **已整合代码**：文献条目改为两行式紧凑列表，只常驻作者、年份、期刊、标签、PDF、HTML 和 Excel 定位；标题打开 Abstract 抽屉。

### 设置与环境体检

- **已整合代码**：首次安装自动展示一次【设置与状态】页，后续不因未配置而反复跳转。
- **已整合代码**：机构、MinerU 和浏览器真实状态只在用户点击【重新检测】后验证。
- **已整合代码**：设置页展示当前实现支持的机构访问、下载、MinerU、本地库和可选增强包状态。
- **待统一验收**：脱敏诊断、真实机构会话和真实宿主状态需按[可靠性整合验收记录](superpowers/executions/2026-09-05-reliability-integration.md)确认。

### PDF 下载

- **已有基线**：合法来源获取、本地 PDF 挂接、PDF 校验和可恢复状态。
- **已整合代码**：对话支持单篇和批量下载；文献页允许为缺失 PDF 的单篇或所选文献执行下载。
- **已整合代码**：先尝试直连获取，剩余项目共用一次机构登录会话；失败或反自动化挑战集中返回给用户。可选增强包不是当前批次编排自动执行的阶段。
- **本轮修复**：单篇预检查异常不再中断整批；重启遗留任务转为可行动的失败状态，保留所选文献；并发状态查询不会争抢同一临时文件。

### 精读 HTML 与资产

- **已有基线**：一个 parent job 串联 PDF、MinerU、逐块翻译、reader 发布与派生更新。
- **已有基线**：任务幂等和重启恢复；PDF 改变会使旧 reader 失效，不覆盖已校验原件。
- **已有基线**：Figure/Table 全量导出、caption、页码、SHA 和可靠来源存在时的 CSV。
- **当前限制**：多个 MinerU/全文翻译任务不并行；不让 AI 自动挑选关键图。
- **已整合代码**：提供离线 Reader 快速审核、固定 baseline/candidate 和分层验收入口；静态/fixture 结果不等于浏览器视觉或真实 DSH 验收。
- **本轮修复**：源 PDF 变化后不复用旧源任务；旧任务查询和旧 worker 不抢占新任务；发布后派生更新可完成，文献保持精读就绪；包清单拒绝包外路径。

### 单篇整理会话

- **已整合代码**：在文献模式中为论文打开可继续讨论的子会话，同一父会话与论文复用绑定。
- **已整合代码**：工具从当前子会话取得论文身份；候选结论须经用户明确确认后入库，已确认结论可导出到受保护的 Excel 工作表。
- **本轮修复**：论文依据绑定 PDF 与 source map SHA，确认及跳转时重新验证；旧定位、个人判断、推断与问题保留各自状态，定位有效不等于科学论断成立。

### 阅读资产恢复与检索

- **已实现**：根级跨进程冻结覆盖受支持的持久写入；版本化整库备份保留数据库、用户字段、历史 generation 和阅读资产。
- **已实现**：仅向新/空目录恢复，拒绝路径/版本/清单/内容异常，恢复任务路径且不使用旧 PID 自动继续；凭据重新配置。
- **已实现**：从已校验历史缓存准备候选重建，精确匹配才复用译文，新增或变化条目保持待完成，旧审核不复用。
- **已实现**：元数据、中英文摘要与已确认结论的可重建 FTS5 索引；文献页显示分类片段与动态证据状态。
- **当前限制**：未覆盖正文/译文全库检索、向量检索或自动语义验证。实际安装包与浏览器结果见本轮验收记录。

### MinerU 解析后端

- **已整合代码**：支持自动、本机和 API 三种策略；自动模式优先经过验证的本机 MinerU。
- **已整合代码**：本机 MinerU 作为外部环境调用，不自动安装 MinerU、CUDA 或模型。
- **已整合代码**：本机和 API 共享规范化、资产校验、manifest 和 cache identity。
- **已整合代码**：API Key 通过 Windows DPAPI 安全保存，不进入普通设置、日志、任务、SQLite 或 Excel；真实 provider 运行仍需验收。

### Excel 长期维护

- **已有基线**：仓库外生成 XLSX；文件占用时保留 pending 并可重试。
- **本轮修复**：行身份冲突、重复身份/表头、文献行缺失、必要工作表异常或文件损坏时，保留原工作簿和未入库笔记；后台任务等待用户修复后重试，写入失败不会标为完成。
- **已整合代码**：把工作簿整理为适合长期维护的个人文献总表。
- **已整合代码**：SQLite 继续保存系统事实；Excel 只对白名单用户字段回写。
- **首批回写字段**：个人思考、个人理解程度和用户笔记。
- **当前限制**：系统字段、文件夹和标签不从 Excel 回写；不会把 Excel 变成完整双向数据库。

## 退出首个发布版

- 飞书同步、飞书配置和飞书字段映射退出当前产品路线；现行运行面不提供这些能力，遗留字段和历史资料仅作兼容与追溯。
- 不提供批量删除、AI 关键图筛选、多个全文重任务并行或在 DSH 页面内嵌整篇 reader。
