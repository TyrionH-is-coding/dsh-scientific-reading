# DSH Scientific Reading 功能清单

## 首个发布版验收范围

### 入库与导航

- **已有基线**：DOI、PMID、arXiv ID、题名与作者录入；稳定标识优先查重。
- **已有基线**：本地事务先返回，题录补全和 Abstract 中英对照在后台继续。
- **已有基线**：全部文献、待归类、文件夹、标签、搜索、筛选、分页、跨页选择和批量归类。
- **发布调整**：文献页回归资料库导航；精读排队、复杂重试等通用任务控制移回对话。
- **发布调整**：文献条目改为两行式紧凑列表，只常驻作者、年份、期刊、标签、PDF、HTML 和 Excel 定位；标题打开 Abstract 抽屉。

### 设置与环境体检

- **发布目标**：首次安装自动展示一次【设置与状态】页，后续不因未配置而反复跳转。
- **发布目标**：机构、MinerU 和浏览器真实状态只在用户点击【重新检测】后验证。
- **发布目标**：展示机构会话、系统 Chrome、CloakBrowser、本地 MinerU、MinerU API、数据根、SQLite、Excel、磁盘空间和版本状态。
- **发布目标**：提供不包含密钥、Cookie、论文内容和用户字段的脱敏诊断报告。

### PDF 下载

- **已有基线**：合法来源获取、本地 PDF 挂接、PDF 校验和可恢复状态。
- **发布目标**：对话支持单篇和批量下载；文献页允许为缺失 PDF 的单篇或所选文献执行下载。
- **发布目标**：整批按 OA/HTTP、系统 Chrome、可选增强包、手动挂接逐层降级；只集中提示一次，不逐篇打断。

### 精读 HTML 与资产

- **已有基线**：一个 parent job 串联 PDF、MinerU、逐块翻译、reader 发布与派生更新。
- **已有基线**：任务幂等和重启恢复；PDF 改变会使旧 reader 失效，不覆盖已校验原件。
- **已有基线**：Figure/Table 全量导出、caption、页码、SHA 和可靠来源存在时的 CSV。
- **当前限制**：多个 MinerU/全文翻译任务不并行；不让 AI 自动挑选关键图。

### MinerU 解析后端

- **发布目标**：支持自动、本机和 API 三种策略；自动模式优先经过验证的本机 MinerU。
- **发布目标**：本机 MinerU 作为外部环境调用，不自动安装 MinerU、CUDA 或模型。
- **发布目标**：本机和 API 共享规范化、资产校验、manifest 和 cache identity。
- **发布目标**：API Key 通过 Windows DPAPI 安全保存，不进入普通设置、日志、任务、SQLite 或 Excel。

### Excel 长期维护

- **已有基线**：仓库外生成 XLSX；文件占用时保留 pending 并可重试。
- **发布目标**：把工作簿整理为适合长期维护的美观个人文献总表。
- **发布目标**：SQLite 继续保存系统事实；Excel 只对白名单用户字段回写。
- **首批回写字段**：个人思考、个人理解程度和用户笔记。
- **当前限制**：系统字段、文件夹和标签不从 Excel 回写；不会把 Excel 变成完整双向数据库。

## 退出首个发布版

- 飞书同步、飞书配置和飞书字段映射退出产品路线；现存实现后续删除，不作为发布能力宣传或验收。
- 不提供批量删除、AI 关键图筛选、多个全文重任务并行或在 DSH 页面内嵌整篇 reader。

## 下一版本候选

- 上游文献发现与推荐：保留发现来源、推荐理由和用户入库 gate。
- 下游逐篇 `.json` 证据卡：保留字段版本、论文身份、结论边界和原文定位，用于综述写作等任务。
