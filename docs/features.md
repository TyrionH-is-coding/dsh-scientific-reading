# DSH Scientific Reading 功能清单

## 快速入库与 Abstract 浅读

- **已完成**：DOI、PMID、arXiv ID、题名与作者录入；稳定标识优先查重。
- **已完成**：本地事务先返回，题录补全、Abstract 翻译和派生同步后台执行。
- **已完成**：只根据来源 Abstract 生成中英对照；缺少摘要时明确标记待补，不按题名编造。
- **当前限制**：不在入库阶段自动下载 PDF、解析全文或生成完整 reader。

## 文献导航与整理

- **已完成**：全部文献、待归类、文件夹、标签、搜索、筛选、分页和长题名展示。
- **已完成**：跨页选择、移动文件夹、添加/移除标签、排队精读、失败重试、飞书重同步及一次完整归类撤销。
- **已完成**：详情与 Abstract 使用临时抽屉；PDF、reader、历史浅读和资产入口按实际状态启用。
- **当前限制**：不提供批量删除，也不在 DSH 页面中嵌入整篇 reader。

## 按需精读与资产

- **已完成**：一个 parent job 串联 PDF、校验、MinerU、逐块翻译、reader 发布与派生更新。
- **已完成**：任务幂等和重启恢复；PDF 改变会使旧 reader 失效，不覆盖已校验原件。
- **已完成**：Figure/Table 全量导出、caption、页码、SHA 和可靠来源存在时的 CSV。
- **当前限制**：多个 MinerU/全文翻译任务不并行；不让 AI 自动挑选关键图。

## XLSX 与飞书派生

- **已完成**：XLSX 是仓库外只读快照；文件占用时保留 pending 并可重试。
- **已完成**：飞书 preview、受管字段白名单、幂等查重、歧义停止和写后读回合同。
- **已完成**：个人思考、理解程度和用户笔记属于用户，系统永不覆盖。
- **当前限制**：没有 SQLite/XLSX/飞书双向同步，不自动修改用户表结构；真实飞书写入仍需针对当次操作明确授权。
